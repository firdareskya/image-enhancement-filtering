# Image Enhancement and Image Filtering

## Deskripsi
Proyek ini merupakan tugas mk pengolahan citra digital - implementasi pengolahan citra digital untuk menganalisis kombinasi Image Enhancement dan Image Filtering pada citra dengan kondisi Salt & Pepper Noise.

## Metode yang Digunakan
1. **Noise:** Salt & Pepper Noise
2. **Image Enhancement:** Histogram Equalization
3. **Image Filtering:** Median Filter

## Skenario Pengujian
- Skenario A: Enhancement saja.
- Skenario B: Filtering saja.
- Skenario C: Enhancement → Filtering.
- Skenario D: Filtering → Enhancement.
- Perbandingan hasil skenario C dan D.

## Teknologi
- Python
- OpenCV
- NumPy
- Matplotlib
- Tkinter

## Instalasi

```bash
pip install opencv-python numpy matplotlib
```

## Cara Menjalankan

Pastikan `main.py` dan `Tomat.jpg` berada dalam folder yang sama.

```bash
python main.py
```

## File
- `main.py`: Program utama.
- `Tomat.jpg`: Citra input untuk pengolahan.
